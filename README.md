# Hire-A-Dog

## Ett projekt jag gjorde i min studie vid Nackademin


Skapad datum: 25/2/19
Senast ändrad 25/2/19
Dokumentansvarig: Sara Svensson: 


INTRODUKTION:
Du ska göra en sida där man kan hyra en hund för en kortare period, 
det ska finnas flera hundar på framsidan som har hyrs ut. 
Det ska finnas någon slags sökfunktion kan tex vara ras, storlek, 
behov osv. Det ska också finnas ett formulär där man fyller i vilken hund man vill hyra, 
hur länge samt ens personuppgifter. Utveckla sidan efter din förmåga med undersidor för 
hundarnas profiler, en eventuell databas, en funktion där man kan skapa en användare osv.

PROJEKTETS SYFTE:
Detta ska vara en sida för personer som vill hyra en hund för en x antal timmar/dagar. 
Hundarna kan hyras för olika behov så som sällskap, jakt, motion.

KRAV:
På framsidan ska det finnas bilder på flera hundar som man kan hyra.
Det ska finnas någon form av sökfunktion där man kan söka på ras, behov osv.
Något sätt att boka en hund tex ett formulär.
Det ska finnas minst 3 hundprofiler.

Språk: svenska eller engelska

TIDSUPPSKATTNING:
2 veckor
